# DET Studio UI

> Rewritten for the [#61](https://github.com/thanhle74/design-engineering-toolkit/issues/61) Ant Design light migration (supersedes the [29]/[52] shadcn/dark doctrine); the structure and gates sections reflect the 2026-11-12 Next.js modular standard and the lane flatten (superseding the nested `modules/` level and `app/*-view` layout).

Read `docs/specs/DET-STUDIO-MVP.md` (note its [#61] stack-supersession note at the top), `docs/specs/NEXTJS-MODULAR-STANDARD.md` (Owner-adopted structure standard), and the current DET schemas before editing. The Engine/CLI is the only conversion authority; Studio never generates Page Builder or PHTML.

1. **Stack:** Next.js App Router + TypeScript + Ant Design 6 (pinned `antd` / `@ant-design/icons` / `@ant-design/nextjs-registry`) used **as-is** — stock antd default light theme, no theme customization (no `ConfigProvider` theme or token overrides; this is the doctrine), with `AntdRegistry` in the root layout. Tailwind is removed from Studio — antd primitives replace its utilities. No shadcn/ui, Radix, Lucide, `cva` or `cn()` — antd primitives are used directly, with tiny feature-specific wrappers only where needed.
2. **Structure (2026-11-12 standard):** `app/**/page.tsx` stays thin — routing, metadata, `connection()`, request-time reads and failure mapping only. Page composition lives in `src/modules/studio/<lane>/screens/*.screen.tsx`, imported through the lane's `index.ts` public API (`@/src/modules/studio/<lane>`). Lanes sit FLAT under `src/modules/studio/` — `overview`, `build-control`, `catalog`, `run-detail`, `conversions`, `design-tree`, `mapping-review`, `preview`, `artifacts`, `agent` — never a nested `modules/` level. Server-only code lives in the lane-independent `src/modules/studio/server/` seam behind `import "server-only"`; client UI never imports it directly. Avoid circular imports and arbitrary abstraction.
3. **Data honesty:** map actual `tool-run.json`, NodeIR, PageStructure and compose outputs; provenance and all `GAP/EXCLUDED/NEEDS_REVIEW` statuses survive. Fixture mode visibly labeled; Preview unavailable is not a failure to hide.
4. **Interactions:** controls must work; disable "run conversion" until [28] supplies a verified safe engine bridge. Do not invoke arbitrary shell commands or read arbitrary client-provided local paths.
5. **UX (internal-tool minimalism, [61] C61-2):** stock antd default sizes; no bespoke styling — an experienced antd user should recognize the UI as stock antd Light. Light-only is an invariant (no dark fallback, toggle or OS-following). This is a small INTERNAL operator tool: keep the shell minimal (no `Layout.Footer`, no header tagline — brand + nav only), pages task-first and sparse (ít chữ), and disclose technical detail progressively behind the stock antd `Collapse` labeled **Chi tiết kỹ thuật** instead of stacking paragraphs. Clear heading hierarchy, accessible antd primitives, readable typography, loading/empty/error/partial/not-connected states. Screenshot and test the working UI.
6. **Copy (Vietnamese, [61] C61-2):** all human-readable UI copy is natural Vietnamese — e.g. **Tổng quan · Build · Dự án** nav, **Chuyển đổi mới**, **Tạo bản dựng**, **Cấu hình build**, **Lần chạy gần đây**, **Xem kết quả**, **Chi tiết kỹ thuật**. Machine vocabulary stays verbatim (never translated): ids, enum/gap/diagnostic codes, paths, env var names, HTTP codes, CLI flags, artifact names, `DEMO`/`LIVE` markers, and product names (`DET Studio`, `Figma`, `det`, `Hyvä`, `Native Page Builder`). When a string doubles as logic or a test fixture (icon branch, prefix check, quoted heading), change copy and the dependent code/test together.
7. **Gates & format (LOCAL only — the repo has no CI):** `pnpm run test:studio` (vitest, currently 375 tests / 37 files), `pnpm run typecheck`, `pnpm run lint`, `pnpm run build` — all on the exact head. Run `pnpm run format` (Prettier, `tabWidth: 3`) before committing.
8. **Build gotchas:** Next 16 Turbopack wraps computed dynamic imports in `trackDynamicImport` — builtin specifiers such as `node:sqlite` fail in PRODUCTION only (dev and vitest pass, CI is gone). A computed specifier needs `/* turbopackIgnore: true */` — see `src/modules/studio/server/catalog/sqlite-driver.ts`. antd's cssinjs injects its rules AFTER `app/globals.css`, so an equal-specificity override loses the cascade — prefix with `body` to win deterministically.
9. **Boundary:** no licensed Hyvä source, client theme or Magento/Figma writes. No auth/database/queue/cloud system in MVP.

## Parallel mode [29]

Read `docs/specs/DET-STUDIO-PARALLEL-WORKERS.md` — its owned-path lists predate the 2026-11-12 flatten; map them onto the flat lanes in rule 2. The lead integrator bootstraps/fixes the shared `StudioRunView` contract first and explicitly opens the parallel gate; only then do worker A (conversions), B (design-tree + mapping-review), C (preview + artifacts) and D (server reader + guarded routes) work simultaneously. Each worker may touch ONLY its owned lane paths. Workers never alter the shared schema/`StudioRunView` contract, the app route shell, the shared provider (`studio-providers`, `app/globals.css`), package/lockfile or Engine — antd is the single UI-primitive source. Ask integrator for shared changes. Workers provide exact changed-file list + targeted test evidence; integrator performs composition, full build, UI verification and the single Draft PR.
