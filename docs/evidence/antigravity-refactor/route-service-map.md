## Highlights for the Integrator (W-A targets)

1. **Inline-logic routes** (extraction candidates): `app/api/agent/analyses/route.ts` POST (catalog+identity+parse glue), `app/api/agent/analyses/[analysisId]/approve/route.ts` (gate+materialize+handoff), `app/api/builds/route.ts` POST, `app/api/build-flow/route.ts` POST, `app/api/runs/[runId]/download-bundle/route.ts` (env default + zip assembly), `app/agent/page.tsx` (redirect shim — fine to keep, it is fully tested).
2. **Env-default duplication:** `download-bundle/route.ts` re-implements the `STUDIO_DET_RUNS_DIR || <cwd>/out/studio-runs` default instead of importing the shared factory default — a drift risk the refactor should close.
3. **Gate discipline is consistent:** every mutating route (`builds` POST, `build-flow` POST, `agent/analyses` POST, `approve` POST) calls `assertStudioEnvironmentReady()` after 400-validation and maps `StudioEnvironmentError` → canonical 503 envelope; cancels and GETs stay ungated. `gate.ts` documents this as the frozen W-B/W-C contract — keep signatures frozen.
4. **Project sub-routes have no colocated tests** (only `app/api/projects/route.test.ts`); DELETE/page-add/delete paths are tested only indirectly, if at all (see `missing-tests.md` M1).
